# «Рядом»: прогресс

Ветка `dev_12_10_2026_1`. План и демо — `docs/nearby-attractions-plan.html`, план второй порции — `docs/favorites-and-search-plan.md`.

## Сделано (этапы 1–2)
- Спайк: `@maplibre/maplibre-react-native` 11.5 работает на RN 0.81 + New Arch (debug-сборка, эмулятор Pixel_9_Pro_XL). WebView-запасной путь не нужен.
- `expo-location`: разрешение «при использовании», позиция = последняя известная (≤2 мин) → `getCurrentPositionAsync(High)` с таймаутом 15 с → старая последняя известная → ошибка с «Повторить».
- Данные: Wikidata SPARQL (значимые места в 5 км, центр по сетке 0,02°, кэш в AsyncStorage на 30 дней) + Wikipedia GeoSearch (ближайшие, пока Wikidata думает; добор, если значимых < 15).
- Вкладка «Рядом»: карта OpenFreeMap (liberty/dark, подписи на `name:ru`), круг 5 км, пины, точка пользователя; список с фото, расстоянием, «≈ N мин», сортировка «Ближе/Известнее», pull-to-refresh, выбор места (камера к месту, подпись на карте).

## Сделано (этапы 3–4)
- Карточка выбранного места: «Маршрут», «Экскурсия», «В навигаторе» (`geo:` — выбор приложения карт), закрыть.
- Маршрут: OSRM FOSSGIS foot (`walking-route-api.ts`, `features/walking-route`), линия на карте, камера по маршруту, «9 мин · 670 м пешком», «Убрать». Пока маршрут на карте — `watchPositionAsync` (шаг 10 м), при сбросе — стоп.
- Экскурсия: название сразу уходит в генерацию (`placeTourStarted`), затем адрес (`reverseGeocodeAsync`, таймаут 3 с) и вводный абзац Википедии (таймаут 3 с) — в `generateTourApi` через `placeTourRequested` → промпт с «Где это», координатами и справкой.

## Сделано (полировка)
- Категории: «Храмы / Музеи / Парки / Памятники / Другое» по названию и описанию (`entities/place/lib/place-kind.ts`), чипы с количеством, фильтр списка и пинов.
- Ссылка «Статья в Википедии» в карточке, подпись источников данных в конце списка.
- «Вы на месте», когда до выбранного места ≤ 40 м при активном маршруте.
- Расстояния в списке — от текущей позиции (раньше — от точки последнего поиска).
- Камера маршрута охватывает и позицию пользователя: OSRM привязывает начало к ближайшей дорожке, позиция может быть в стороне.
- Источники карты монтируются всегда (пустые данные вместо условного монтирования) — порядок слоёв стабилен.

## Сделано (после первого APK)
- Радиус 500 м / 1 км / 2 км / 5 км: переключатель поверх карты (`radius-switch.tsx`), выбор сохраняется (`STORAGE_KEYS.NEARBY_RADIUS`). Запросы всегда на максимум, сужение — фильтром на клиенте.
- Выбранное место: панель показывает только карточку, список спрятан (`display: 'none'`) и не теряет скролл. Карточка и список — две разные панели: переключение flex-стиля на одной панели Yoga раскладывала неверно.
- Стабильный список: статьи GeoSearch с категорией (храм/музей/парк/памятник) объединяются с Wikidata всегда, без категории — только если значимых < 15. Wikidata `LIMIT 200` (первый запрос по району до ~30 с), ключ кэша `_v2`.
- Озвучка в фоне: `speech-model.ts` ставит все оставшиеся предложения в очередь TTS сразу (`speakQueueFx` + `$generation` против событий старой очереди). Проверено: 11 из 12 предложений дочитаны со свёрнутым приложением; перемотка, скорость, «Стоп» работают.
- Починен импорт `BASE_CHARS_PER_SECOND` (не экспортировался из `shared/config` → интервал подсветки слов был `NaN`).

## Сделано (избранное, город, свободный поиск, VPN) — план `favorites-and-search-plan.md`
- Подсказка про VPN: `getGroqErrorMessage` — 403/«region» → «Groq недоступен из вашего региона…», `NETWORK_ERROR`/`TIMEOUT` → «Не удалось подключиться к Groq… попробуйте VPN». Починен `api-client.ts`: `instanceof DOMException` в Hermes бросал ReferenceError, и вместо сетевой ошибки показывалось «Property 'DOMException' doesn't exist».
- Избранное (`entities/favorite`): снимок места в AsyncStorage, группы (одна у места), цвет у группы и у места (место переопределяет), по умолчанию жёлтый с красной обводкой. На карте отдельный источник `nearby-favorites` — виден в любом режиме; избранное из другого города открывает карточку через `$selectedPlace` (снимок). Карточка: звёздочка, чип группы (выбор/создание), цвет. Панель: вкладки «Рядом | Избранное · N», список «Мои группы / По типам», правка и удаление группы (места → «Без группы»). Камера в «Избранном» — по всем избранным.
- «Город»: Nominatim reverse `zoom=10` (рамка, `osmId`) → Wikidata `wikibase:box`, порог известности по площади (≤600 км² → 3, ≤1500 → 8, больше → 15), таймаут 70 с, кэш по `osmId` (5 городов, 30 дней). Рамка на карте и камера по ней. Москва: 222 места за 55 с (первый раз), Калуга: 29 мест за 9 с.
- «Свободно»: `onRegionDidChange` + debounce 700 мс; с зума 10 — плитки Wikidata 0,1° (≤4 за сдвиг, ближние к центру, порог 3) + GeoSearch `gsbbox` (рамка > 380 км² ужимается — иначе `toobig`). Места копятся по id, камера сама не двигается. Центр Москвы: 373 места в кадре за ~24 с. Холодный старт в этом режиме — `initialViewState` у камеры.
- `formatDistance` от 10 км — целые км, «≈ N мин пешком» в строке места — только до 10 км.

## Сделано (качество мест, место под список, экскурсия без координат)
- Качество: SPARQL отдаёт прямые классы P31, состояние сохранности P5816 и статус наследия P1435. Фильтр `entities/place/lib/sight-quality.ts`:
  - снесённые (P5816 «снесено», кроме «реконструкции»), утраченные и недостроенные — всегда вон;
  - «мусорные» классы (заводы, компании, аэропорты, водохранилища, гостиницы, вокзалы, НИИ, архивы, больницы, вузы, школы, дороги, спорт) — только при статусе наследия или ≥ 40 sitelinks;
  - остальное — при статусе наследия (в т. ч. P31 «памятник архитектуры/истории»), категории храм/музей/парк/памятник, культурном классе (театр, дворец, крепость, площадь, ансамбль) или ≥ 8 sitelinks.
  - Порог в радиусе 8 → 3. Статьи GeoSearch без категории не берутся, «сквер» больше не парк. Ключи кэша `_v4` / `_v3`.
  - Итог: Калуга 5 км — 19 мест без заводов, аэропорта, водохранилища и скверов; Москва 5 км — 156 (было 173+ с мусором), город — 214.
- Раскладка: кнопка «Развернуть список» в строке вкладок — карта сжимается в полосу 150 dp (`height`, а не `flexBasis`: смену `flexBasis` 0 → 150 Yoga не применяла, карта схлопывалась в 0). Строка заголовка убрана: количество — во вкладке «Рядом · N», сортировка — чип-переключатель в ленте категорий, в режиме «Город» на переключателе название города. На 412 dp: 4 строки списка свёрнуто, 9 развёрнуто.
- Экскурсия: координаты из промпта убраны, адрес и справка — блоком «служебные данные, не зачитывай»; в системном промпте первый абзац — с самого яркого факта, адреса и координаты называть запрещено. С реальным ключом Groq не проверено.

## Не сделано
- Фоновая речь без foreground-сервиса: в `dumpsys audio` есть запись `AudioHardening background playback would be muted for com.google.android.tts` — на эмуляторе только предупреждение. Если на каких-то прошивках речь в фоне глушится — нужен сервис с уведомлением (новый нативный пакет).
- Резервный маршрутизатор ORS — нужен бесплатный ключ openrouteservice.org.
- Сохранение экскурсии с координатами (`Tour.location`) — пока ничем не используется.
- Генерация с контекстом не проверена до конца: на эмуляторе нет ключа Groq.
- Overpass, категории, офлайн — по желанию.

## Гочи
- Metro с `CI=1` не следит за файлами — правки не доходят до устройства. Запускать `npx expo start --dev-client` без CI.
- Картинки Wikimedia с User-Agent okhttp → 403: в `Image` передаём `headers: { 'User-Agent': APP_USER_AGENT }`.
- На эмуляторе `Accuracy.Balanced` не включает GPS (нет сети-провайдера) — нужен `High`; `adb emu geo fix` доходит, только пока GPS запрошен.
- `console.log` из JS не виден ни в Metro (RN 0.81), ни в logcat — отлаживать через DevTools или временный вывод на экран.
- `useUnit({ kind: ... })` ломается: effector считает объект с полем `kind` юнитом → «e.getState is not a function». Ключ `kind` в shape не использовать.
- `\b` в JS-регулярках — только для латиницы; конец слова по кириллице — `(?![а-яё])`.
- `KeyboardAvoidingView` в `Modal` на Android без `behavior` не работает (edge-to-edge): клавиатура закрывает шторку. Нужен `behavior="padding"`.
- `adb shell wm density 597` ≈ 360 dp на Pixel 9 Pro XL; после смены плотности без перезапуска процесса RN обрезает текст — проверять после force-stop.
- Item Wikidata может иметь несколько координат P625: around- и box-запросы иногда отдают разные строки, расстояние до одного места в списке и карточке может отличаться на десятки метров.
